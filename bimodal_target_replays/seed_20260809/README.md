# Bimodal-Target successful L/R replay export

The formal Bimodal-Target analysis contains 20 successful realised-L rollouts
and 53 successful realised-R rollouts. With selection seed `20260809`, the
exporter selected and successfully reproduced:

- `L`: B05, evaluation case 04, repeat 1, policy seed 20310848.
- `R`: B03, evaluation case 08, repeat 0, policy seed 20290887.

Each route directory now contains the active **world-y mirrored**
`intervention.csv` for the left-handed setup. To keep the unrelated
repository-root file untouched while using a replay command that expects
`./intervention.csv`, run the replay from the selected route directory:

```bash
cd bimodal_target_replays/seed_20260809/L  # or R
# Run the existing replay command here; ./intervention.csv is the selected case.
```

The original positive-y joint CSV is retained as
`intervention_y_positive_original.csv`. The active trajectory was generated by
FK of the original joints with the source base at `[0, +0.15, 0]`, changing
world Cartesian position `y := -y`, mirroring the base to `[0, -0.15, 0]`, and
then sequential PyBullet IK/replay. World EE orientation is unchanged; adjacent
orientations are interpolated using quaternion SLERP.

The active CSV covers the scripted initial EE pose, grasp/lift, and learned-
policy transport/release. `gripper_width` is the measured sum of both simulated
finger-joint positions (approximately 0.08 m open and 0.0 m closed), while
`gripper_cmd` uses `-1=open`, `+1=closed`.

The mirror exporter uses at least four Cartesian interpolation points per
source transition and adaptively increases this to 64 to keep planned joint
steps below 0.01 rad. The active 30 Hz trajectories are 55.07 s / 1,653 rows
for L and 61.47 s / 1,845 rows for R. Maximum implied joint velocities are
0.291 and 0.298 rad/s; maximum EE tracking errors in PyBullet are 1.37 mm and
1.26 mm.

These remain PyBullet states, not hardware-certified trajectories. Before
commanding a physical robot, verify frame/base calibration, the first joint
state, collision clearance, and controller velocity/acceleration limits.

See each `intervention_y_mirror.json` and the root `manifest.json` for mirror
provenance, hashes and validation metrics. The reproduction MP4 files show the
pre-mirror positive-y simulation and are retained only as source evidence. See
`successful_lr_cases.csv` for all 73 formal successful L/R candidates.
