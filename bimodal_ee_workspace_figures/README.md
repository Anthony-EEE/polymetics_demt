# Bimodal EE workspace figures

All figures show retained successful demonstration EE trajectories.
Each participant panel contains exactly 30 L and 30 R demonstrations.
The x-y plots are top views; the x-z plots show height. Axes are fixed
across all participants and both experiments.

- Blue: L route
- Orange: R route
- Gray: obstacle
- Green: target/release context

Overview PNG files are in this directory. Individual XY+XZ PNGs
are under `per_participant/`.
